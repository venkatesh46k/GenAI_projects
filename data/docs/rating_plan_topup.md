# Data Top-up Packs (PLAN_99)

Data top-up packs give a subscriber extra data on top of an active base plan. They contain data only: no voice minutes and no SMS.

## Data Topup 99 (PLAN_99)

| Item | Value |
|---|---|
| Plan ID | PLAN_99 |
| Price | ₹99 |
| Validity | 30 days |
| Data | 1 GB per day |
| Voice | 0 minutes |
| SMS | 0 |

## Rules

- **Requires an active base plan.** A top-up can only be bought while the subscriber has a valid base plan such as PLAN_199 or PLAN_599. Buying a top-up on an expired line only credits the balance; the data benefit is not usable until a base plan is active.
- **Data is additive.** Top-up data is added to the daily quota of the base plan. For example, a PLAN_199 subscriber with a Data Topup 99 has 1.5 GB + 1 GB = 2.5 GB per day.
- **Consumption order.** The base plan quota is consumed first, then the top-up quota.
- **Validity is independent.** The top-up runs for its own 30 days. If the base plan expires before the top-up does, the unused top-up data is not usable until a base plan is active again, and the top-up validity keeps running.
- **No refund for unused data.** Top-up packs are non-refundable once activated, except in the case of a failed activation (see the refund policy).
- **Voice and SMS are still charged separately.** A top-up does not include voice or SMS, so those follow the base plan or out-of-bundle rates.

## Stacking

A subscriber can buy more than one top-up. Buying the same pack again extends its validity by 30 days from the current top-up expiry. It does not raise the daily quota, which stays at 1 GB.
